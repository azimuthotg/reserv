# Progress 2026-08-02 — สารบัญคู่มือมีเลขหน้า + เริ่มนับหน้า 1 ที่บทที่ 1

เครื่องมือ: Claude Code edit

## ปัญหา

คู่มือผู้ใช้ `doc/user-manual-reserv-2569.docx` สารบัญไม่มีเลขหน้า

สาเหตุอยู่ที่ `doc/manual_style.py` เมธอด `Manual.toc()` เขียนสารบัญเป็น**ข้อความธรรมดา**
บรรทัดละหัวข้อ (`f"{label}  {title}"`) ไม่ใช่ TOC field ของ Word จึงไม่มีทั้งจุดไข่ปลาและเลขหน้า
python-docx คำนวณเลขหน้าเองไม่ได้เพราะไม่รู้การจัดหน้า ต้องให้ Word เป็นคนเติม

เพิ่มเติม: `page_numbers()` ใส่ footer ที่ section เดียวของเอกสาร ปกจึงถูกนับเป็นหน้า 1

## สิ่งที่แก้

### 1. `doc/manual_style.py` — ต้นทางของคู่มือทุกเล่ม

- เพิ่ม `ensure_toc_styles(doc)` สร้าง style `toc 1–3` (TH Sarabun New + `w:cs`/`w:szCs`
  + tab ชิดขวาจุดไข่ปลาที่ 16 ซม.) เพราะ Word จะสร้างย่อหน้าสารบัญด้วย style เหล่านี้ทับของเดิม
  ถ้าไม่กำหนดเอง ข้อความไทยจะกลับไปใช้ฟอนต์เริ่มต้นของ Word
- เพิ่ม `wrap_toc_field(first_p, last_p)` ครอบรายการสารบัญด้วย field
  `TOC \o "1-3" \h \z \u` (ตั้ง `w:dirty="true"` ให้ Word อัปเดตตอนเปิด)
  รายการเดิมกลายเป็น field result สำรอง จึงยังอ่านได้ในโปรแกรมที่ไม่อัปเดต field
- `toc()` ใช้ helper ทั้งสอง แล้วปิดท้ายด้วย `add_section(WD_SECTION.NEW_PAGE)` แทน `add_page_break()`
- `page_numbers()` ใส่ footer เฉพาะ section สุดท้าย (เนื้อหา) และเพิ่ม `w:pgNumType w:start="1"`
  → ปก + สารบัญ ไม่มีเลขหน้า, บทที่ 1 = หน้า 1

รายการที่ส่งให้ `m.toc([...])` ยังต้องเรียงตรงกับหัวข้อจริง แต่ไม่ต้องใส่เลขหน้าเอง

### 2. `doc/fix_manual_toc.py` (ใหม่) — แพตช์ไฟล์ .docx ที่มีอยู่แล้ว

ใช้กับไฟล์ที่ถูกแก้ด้วย Word ไปแล้ว จึงรันสคริปต์สร้างใหม่ไม่ได้ (งานแก้มือจะหาย)
ทำ 3 อย่างกับไฟล์เดิม: ครอบ TOC field รอบรายการสารบัญเดิม, เติม style `toc 1–3`,
เปลี่ยน page break หลังสารบัญเป็น section break แล้วตั้งให้เนื้อหาเริ่มนับหน้าที่ 1
ใช้ helper ร่วมกับ `manual_style.py` เพื่อไม่ให้สองที่หลุดกัน · รันซ้ำได้ (ข้ามขั้นที่ทำไปแล้ว)
· สำรองไฟล์เดิมเป็น `*.before-toc.docx` อัตโนมัติ

```bash
python3 doc/fix_manual_toc.py doc/user-manual-reserv-2569.docx
```

### 3. `doc/user-manual-reserv-2569.docx` — ไฟล์ที่ใช้งานจริง

รันแพตช์ แล้วให้ Word (COM) อัปเดต field และ save เพื่อ **ตรึงเลขหน้าไว้ในไฟล์**
สารบัญจึงแสดงเลขหน้าแม้เปิดด้วยโปรแกรมที่ไม่อัปเดต field

## วิธีตรวจสอบ

- โครงสร้างไฟล์: 2 section — section 0 (ปก+สารบัญ) ไม่มี `footerReference`,
  section 1 มี `footerReference` + `pgNumType start=1`
- Word COM อัปเดต field ได้: `TablesOfContents.Count = 1` และ TOC range มี tab + เลขหน้า
- แปลง PDF ด้วย LibreOffice: 24 หน้า — สารบัญมีจุดไข่ปลา + เลขหน้าครบ 21 บรรทัด
  (Word เก็บ `การติดต่อสอบถาม` เพิ่มจากรายการเดิม), หน้า 1–2 ไม่มีเลขหน้า,
  หน้าถัดมาเป็น 1, 2, 3 ตามลำดับ
- เนื้อหาไม่หาย: ตาราง 15, ภาพ 16 เท่าเดิมทั้งก่อนและหลังแพตช์
- ทดสอบ `manual_style.py` ด้วยเอกสารย่อ 4 หน้า — ได้ 2 section, TOC field, style TOC1-3
  และเลขหน้าเริ่มที่บทที่ 1 ถูกต้อง
