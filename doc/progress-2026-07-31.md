## สิ่งที่ทำ

### 1. ตอบคำถามเรื่องภาพหน้าจอมือถือ (ไม่มีมือถือมาแคป)

สรุป: **ทำได้โดยไม่ต้องมีมือถือจริง** — ใช้ Playwright emulate iPhone (viewport 390×844, DPR 3)
เปิดเว็บ production จริง ได้ภาพเหมือนแคปจากมือถือทุกพิกเซล เพราะเป็น HTML/CSS ชุดเดียวกับที่มือถือเรนเดอร์

ข้อจำกัดที่ emulate ไม่ได้ (เป็น UI ของแอป LINE ไม่ใช่หน้าเว็บเรา):
Rich Menu, หน้ายินยอม LINE Login, ฟองข้อความแจ้งเตือนใน chat, กล้องสแกน QR ที่ประตู
→ คู่มืออธิบายด้วยข้อความแทน ถ้าต้องการภาพจริงค่อยแคปจากมือถือแล้วแทรกเพิ่มภายหลัง

### 2. เก็บภาพหน้าจอจาก production จริง

| ชุด | จำนวน | วิธีเก็บ |

| หน้าสาธารณะ (เว็บ + มือถือ) | 14 ภาพ | Playwright headless ไม่ต้อง login |

เก็บไว้ที่ `doc/screenshots/manual2026/` และภาพประกอบ 16:9 ที่รวมแล้วอยู่ที่ `composed/`

### 3. แก้ปัญหาอัตราส่วน 16:9 ของภาพมือถือ

จอมือถือเป็น 9:16 วางเดี่ยวในกรอบ 16:9 จะเหลือขอบว่างมาก
→ เขียน `doc/compose_mobile_figures.py` เรียงได้สูงสุด 3 จอในกรอบ 1920×1080 พร้อมเลขลำดับขั้น
ส่วนภาพฝั่งเจ้าหน้าที่เป็น 1920×1080 = 16:9 อยู่แล้ว ใช้ตรง ๆ

### 4. สร้างการจองทดสอบเพื่อเก็บภาพที่ขาด (แล้วยกเลิก)

บัญชีที่ login ไม่มีการจองค้าง ทำให้ขาดภาพหน้าจองสำเร็จ / รายละเอียดการจอง / ปุ่ม Check-in / ปุ่มควบคุมอุปกรณ์

- สร้าง booking `#445` (08:30–08:40) → ยกเลิก
- สร้าง booking `#446` (08:30–09:30 กลุ่มโปรเจกต์วิชาสัมมนา) → เก็บภาพครบ → ยกเลิก
- **ยืนยันแล้วทั้ง 2 รายการเป็นสถานะ `ยกเลิก` ที่ `/manage/bookings/`** ไม่มีการจองค้างในระบบ

ปุ่ม Check-in และปุ่มควบคุมอุปกรณ์เรนเดอร์ฝั่ง JS จาก `new Date()`
จึงเก็บภาพได้โดย**เลื่อนนาฬิกาในเบราว์เซอร์แล้วเรียก `renderMyBookings()` ซ้ำ** — ไม่แตะข้อมูลฝั่ง server

## จุดที่ต้องระวัง (บทเรียนจากงานนี้)

**ข้อความไทยใน Word ใช้ฟอนต์ช่อง Complex Script** — `python-docx` ตั้งให้แค่ `w:ascii`/`w:hAnsi`/`w:sz`
แต่ Word จัดภาษาไทยเป็น complex script จึงอ่านฟอนต์จาก `w:cs` และขนาดจาก `w:szCs`
ถ้าไม่ตั้งสองค่านี้ ข้อความไทยทั้งเอกสารจะกลายเป็นฟอนต์และขนาดเริ่มต้นของ Word
→ แก้ด้วย `_thai_run()` ใน `doc/manual_style.py` เรียกทุก run และทุก style
(สคริปต์ `make_*.py` ชุดเก่าใน `doc/` ยังไม่ได้แก้จุดนี้)

ฟอนต์ `TH Sarabun New` ยืนยันแล้วว่าติดตั้งอยู่บนเครื่อง (`/mnt/c/Windows/Fonts/`)
ระวังสับสนกับ `TH SarabunPSK` ซึ่งเป็นคนละ family

## งานค้างจากคู่มือชุดนี้

1. **หน้าควบคุมอุปกรณ์ตอนมีอุปกรณ์จริง** — `/api/room-status/` ตรวจ booking ที่ active **ฝั่ง server**
   เลื่อนนาฬิกาเบราว์เซอร์ไม่ช่วย ต้องแคปช่วงเวลาเปิดบริการจริง (08:30–16:30) ขณะมีการจอง active
   ตอนนี้คู่มือใช้ภาพสถานะ "ไม่มีการจองในขณะนี้" พร้อมคำบรรยายตามจริง
2. 4 ภาพที่เป็น UI ของแอป LINE (Rich Menu / หน้ายินยอม LINE Login / ฟองข้อความแจ้งเตือน / กล้องสแกน QR)
   ยังเป็นข้อความอธิบาย รอผู้ใช้แคปจากมือถือส่งมาแทรก
3. ภาพหน้าจอมีข้อมูลส่วนบุคคลจริง (ชื่อ-สกุลผู้จอง, รูปถ่าย, เลข 13 หลักใต้ QR)
   ผู้ใช้ยืนยันให้คงไว้ตามเดิม — **ถ้าจะเผยแพร่นอกหน่วยงานควรเบลอก่อน**
