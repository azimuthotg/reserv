# ตอบกลับ: ดำเนินการเปลี่ยนบริการจาก Netflix เป็น ChatGPT เรียบร้อยแล้ว

**ถึง:** ทีมพัฒนา LRS ARC VM Gateway
**จาก:** ผู้ดูแลระบบจองพื้นที่บริการ (reserv) สำนักวิทยบริการ มหาวิทยาลัยนครพนม
**วันที่:** 9 ส.ค. 2569
**อ้างถึง:** ใบแจ้งขอเปลี่ยนบริการ จาก Netflix เป็น ChatGPT ลงวันที่ 9 ส.ค. 2569

---

## 1. ดำเนินการครบทุกข้อแล้ว — เริ่มผูก Gateway ได้ทันที

| ข้อ | รายการที่ขอ | สถานะ |
|---|---|---|
| 1 | `netflix1_vm` (id 6) → `is_active = 0` | ✅ เรียบร้อย |
| 2 | `chat-gpt` (id 4) → `is_active = 1` | ✅ เรียบร้อย |
| 3 | `chat-gpt` → `open_time = 00:00`, `close_time = 23:59` | ✅ เรียบร้อย |
| 4 | `chat-gpt` → `is_online = 1` | ✅ เรียบร้อย |
| 5 | ไม่ลบห้องและไม่ลบประวัติการจอง | ✅ เก็บครบ — `netflix1_vm` 20 รายการ · `chat-gpt` 16 รายการ |
| 6 | แจ้งกลับเมื่อเสร็จ | ✅ หนังสือฉบับนี้ |

**`booking_name` ที่ต้องใช้ผูกกับ `VMMachine.room_key` คือ `chat-gpt`** (ไม่เปลี่ยน id ยังเป็น 4)

### ตรวจก่อนดำเนินการ

ยืนยันตรงกับที่ทีมพัฒนาแจ้ง — **`netflix1_vm` ไม่มีการจองสถานะ confirmed ตั้งแต่ 9 ส.ค. เป็นต้นไป
เลยแม้แต่รายการเดียว** (รายการ confirmed ล่าสุดคือ 19 ก.ค. 2569) จึงปิดได้ทันทีโดยไม่กระทบผู้ใช้
และไม่ต้องยกเลิกรายการใด

## 2. แก้เนื้อหาห้อง `chat-gpt` เพิ่มเติมจากที่ขอ

ข้อมูลห้อง `chat-gpt` ยังเป็นของสมัยที่เป็น **เครื่องคอมพิวเตอร์จริงที่ชั้น 1** ถ้าเปิดห้องโดยไม่แก้
นักศึกษาที่จองรอบตี 2 จะเห็นคำแนะนำว่าให้เดินมาที่ชั้น 1 และเปิดเครื่องคอมพิวเตอร์
จึงเขียนใหม่ให้ตรงกับการเป็นบริการผ่านเครื่องเสมือน โดยยึดรูปแบบเดียวกับห้อง Canva

| ฟิลด์ | เดิม | ใหม่ |
|---|---|---|
| `location` | ชั้น 1 สำนักวิทยบริการ | ออนไลน์ (เครื่องเสมือน ใช้งานผ่านเว็บ) |
| `description` | คอมพิวเตอร์ ChatGPT Plus 1 เครื่อง | เครื่องคอมพิวเตอร์เสมือนสำหรับใช้งาน ChatGPT (1 บัญชี) ใช้งานผ่านเว็บ ไม่ต้องเข้าอาคาร |
| `facilities` | เครื่องคอมพิวเตอร์ | เครื่องคอมพิวเตอร์เสมือน + บัญชี ChatGPT (1 บัญชี เฉพาะเครื่องนี้) |
| `eligible_users` | *(ว่าง)* | นักศึกษา คณาจารย์ และบุคลากร มหาวิทยาลัยนครพนม |
| `rules` / `how_to_use` | อ้างอิงเครื่องจริงที่ชั้น 1 | เขียนใหม่ตามรูปแบบบริการเครื่องเสมือน |

เพิ่มข้อควรระวังในกฎการใช้ห้องด้วยว่า **เป็นบัญชีที่ใช้ร่วมกันหลายคน ไม่ควรพิมพ์ข้อมูลส่วนบุคคล
หรือข้อมูลลับลงในบทสนทนา และควรลบประวัติการสนทนาก่อนเลิกใช้งาน** เนื่องจากผู้ใช้คนถัดไป
อาจเห็นประวัติการสนทนาของคนก่อนหน้าได้

**ยังไม่ได้ระบุ URL ของเว็บ Gateway ใน `how_to_use`** เขียนไว้กว้าง ๆ ว่า
"เข้าใช้งานเครื่องคอมพิวเตอร์เสมือนผ่านเว็บของสำนักวิทยบริการ" เพราะยังรอ URL แบบ https + domain
(ดูข้อ 4)

## 3. ⚠️ ขอแก้ความเข้าใจเรื่องเวลาจองสูงสุด

ในใบแจ้งระบุว่า `max_booking_hours = 2 (ตรงแล้ว)` — ขอเรียนว่า **ฟิลด์นี้ระบบจองไม่ได้ใช้บังคับ**
ตรวจสอบเมื่อ 9 ส.ค. 2569 พบว่าเพดานจริงถูกกำหนดไว้ในโค้ดเป็น **210 นาที = 3.5 ชั่วโมง
เท่ากันทุกห้อง** มาตลอด ส่วนค่า 2 ในฐานข้อมูลเป็นค่า default ของระบบที่ไม่เคยถูกนำไปใช้

สำนักฯ ยืนยันแล้วว่า **3.5 ชั่วโมงต่อครั้งคือค่าที่ถูกต้อง** ระบบจองจึงปรับหน้าจอให้แสดงตรงกับ
ของจริงและถอดฟิลด์ที่ไม่มีผลออกจากหน้าจัดการห้องแล้ว

**สรุปเพดานเวลาที่ผู้ใช้จองได้จริง — เป็น "ค่าที่น้อยที่สุด" ใน 3 ข้อนี้**

1. 3.5 ชั่วโมงต่อครั้ง
2. เวลาเปิด-ปิดของบริการนั้นในวันนั้น (ChatGPT = 00:00–23:59 ทุกวัน)
3. ขอบของรอบบริการ — **ห้ามจองคร่อมรอบ**

| รอบบริการ | ช่วงเวลา |
|---|---|
| เช้ามืด | 00:00–08:30 |
| กลางวัน | 08:30–17:00 |
| กลางคืน | 17:00–23:59 |

ตัวอย่างสำหรับ ChatGPT: เริ่ม 20:00 จองได้ถึง 23:30 (3.5 ชม. เต็ม) · แต่เริ่ม 16:00 จองได้ถึง 17:00
เท่านั้น (1 ชม.) เพราะชนขอบรอบกลางวัน · **ผู้ใช้ 1 คนจองได้รอบละ 1 ครั้งต่อบริการ
รวมสูงสุด 3 รอบต่อวันต่อบริการ**

หากทีมพัฒนาต้องการให้ Gateway ตัด session ตามเวลาจอง ขอให้อ่านจาก `start_time`/`end_time`
ของแต่ละรายการโดยตรง ไม่ต้องคำนวณจากเพดานชั่วโมง

## 4. เรื่องที่ยังรอจากทีมพัฒนา

1. **URL เว็บ Gateway แบบ https + domain** (ที่แจ้งไว้ว่ากำลังรอทีม DNS)
   ระบบจองเตรียมงาน 2 อย่างไว้รอแล้ว คือ (ก) เติม URL ลงใน `how_to_use` ของทั้ง 3 บริการ
   และ (ข) เปลี่ยนปุ่มบนหน้าจองของบริการเครื่องเสมือน จากปุ่ม "ควบคุมอุปกรณ์ไฟฟ้า"
   เป็นปุ่ม **"เข้าใช้งาน"** ที่เปิดแท็บใหม่ไปหน้า login ของ Gateway
   *(URL ทดสอบที่ได้รับไว้แล้วคือ `http://202.29.55.180:8888/vm/login`
   ยังไม่นำไปใช้จริงเพราะเป็น http และเป็น IP)*
2. **ตารางบำรุงรักษา / รีสตาร์ตเครื่องแม่ประจำคืน** เพื่อกันไม่ให้เปิดจองคร่อมช่วงนั้น
3. ยืนยันกลับเมื่อผูก `VMMachine.room_key = 'chat-gpt'` และรัน `check_booking_mapping` เรียบร้อย

## 5. หมายเหตุอื่น

- **Netflix ที่ Edutainment Zone ชั้น 3 ยังให้บริการตามปกติ** การปิด `netflix1_vm` ครั้งนี้
  กระทบเฉพาะบริการผ่านเครื่องเสมือนเท่านั้น ไม่เกี่ยวกับจุดบริการที่ชั้น 3
- **ความจุของ Canva Pro 1/2 ปรับเป็น 1 คนแล้ว** (จากเดิม 2) ตามที่สำนักฯ ยืนยันว่าเป็นการใช้งาน
  ส่วนบุคคลเครื่องละคน จึงตรงกับ ChatGPT ที่ตั้งไว้ 1 คนอยู่แล้ว — บริการเครื่องเสมือนทั้ง 3 ตัว
  ตอนนี้ตั้งค่าเหมือนกันหมด
- ประวัติการจองของ `chat-gpt` ที่มี 16 รายการนั้น มีสถานะ confirmed 6 รายการ
  (ล่าสุด 29 ก.ค. 2569) ที่เหลือเป็นรายการที่ถูกยกเลิก
- รูปประกอบของห้อง `chat-gpt` ยังเป็นภาพเครื่องคอมพิวเตอร์จริงชุดเดิม อยู่ระหว่างจัดทำภาพใหม่
  ให้เข้าชุดกับบริการเครื่องเสมือนอื่น ไม่กระทบการใช้งาน
